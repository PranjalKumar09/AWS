Amazon S3 + CloudFront CDN Demo

This page demonstrates how to serve images from Amazon S3 and later accelerate delivery using Amazon CloudFront CDN.

Image Served from S3

Image URL: https://your-bucket-name.s3.amazonaws.com/demo-cat.png

Image Served from CloudFront (after setup)

Image URL: https://your-distribution-id.cloudfront.net/demo-cat.png

How to Use

  1. Upload your image (demo-cat.png) to S3 bucket.
  2. Make sure the bucket/object is public OR accessible by CloudFront.
  3. Update the first image tag with your real S3 link.
  4. Create a CloudFront distribution that points to your S3 bucket.
  5. Replace the second image tag with your CloudFront domain link.
