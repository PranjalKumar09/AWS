Route 53

upto now we used ip address, for getting real name like address we use route 53
It is scalable DNS serivce for domain registration traffic routing & health checking capabilities

DNS (Domain Name System) is internet service that translate human friendly domain like www.example.com into machine readable IP address

Default port for DNS service is 53

we can also set health checker in it
  first we have to set it
  then set for region range, each region we have to do


Domain Name Registration
Hosted zone creation
DNS records: Add record (eg CNAME, MX) to route traffic to various endpoint
Routing Policies: Set up routing polices based on your needs, such as latency based or failover routing
Health Checks: Configure health check to monitor endpoint & trigger




Type of Records 
  A Record: Ipv4 address, www.google.com -> 12.34.45.67
  AAAA record: (Ipv6): Maps domain name to an IPv6 address, www.example.com: 2001:db8:1
  CNAME record: Maps domain name to another domain name (alias)
    blog.example.com => www.example.com
  MX record: Directs mail to an email server
    example.com => mail.example.com (Priority 10)

  

Use Cases

  Hosted Website
  Load Balancing: Distribute traffic across multiple endpoints using weighted or latency based routing
  Disaster Recovery: Use health checks & failover routing for high availability.
  Multi Region Deployment: Nearest got lowest latency
